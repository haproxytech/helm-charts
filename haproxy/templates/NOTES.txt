To be able to bind to privileged ports as non-root, the following is required:

securityContext:
  enabled: true
  runAsUser: 1000
  runAsGroup: 1000
initContainers:
  - name: sysctl
    image: "busybox:musl"
    command:
      - /bin/sh
      - -c
      - sysctl -w net.ipv4.ip_unprivileged_port_start=0
    securityContext:
      privileged: true

{{- $memLimit := dig "limits" "memory" "" (.Values.resources | default dict) }}
{{- if not $memLimit }}

NOTE: no memory limit is set (resources.limits.memory).

The container may then use as much memory as the node has, and under memory
pressure the node's OOM killer chooses which pod to evict, possibly an
unrelated workload, instead of this pod being restarted against a ceiling of
its own. How much HAProxy needs depends on your configuration: buffers,
concurrent connections, stick tables, maps and SSL caches all contribute.

Set a limit sized against your own configuration, for example:
  --set resources.limits.memory=256Mi
{{- end }}
